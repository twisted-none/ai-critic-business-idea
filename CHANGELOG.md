# Changelog

## [1.1.3] - 2026-10-30

### Changed

- Явно неполное описание сразу переводится в сценарий уточнения без лишнего вызова модели.

## [1.1.2] - 2026-10-30

### Fixed

- Для явно неполного описания добавлен безопасный сценарий уточнения, если бесплатная модель возвращает некорректный формат.

## [1.1.1] - 2026-10-30

### Changed

- Во всех пользовательских текстах теперь используется термин «презентация».
- Ответы бесплатных моделей нормализуются без потери обязательных полей сценария.
- Тестовая команда запускает только интеграционный набор, не включая локальный mock-сервер.

## [1.1.0] - 2026-10-30

### Added

- Три режима AI-ответа: анализ, уточнение данных и передача специалисту.
- Краткое резюме и обязательный следующий шаг.
- Адаптивный интерфейс с доступными состояниями загрузки, ошибки и результата.
- Ограничение частоты запросов и строгая проверка ответа модели.

### Changed

- Системный промпт приведён к структуре итогового задания и вынесен в отдельный файл.
- Production-сборка всегда отключает деморежим.

### Security

- Добавлены CSP и другие защитные HTTP-заголовки.
- Обновлены транзитивные зависимости; `npm audit` не находит уязвимостей.
