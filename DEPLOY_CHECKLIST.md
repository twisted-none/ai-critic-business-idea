# Чек-лист публикации и сдачи

## Один раз перед публикацией

1. В OpenRouter создайте API-ключ: `https://openrouter.ai/settings/keys`.
2. Загрузите эту папку в новый репозиторий GitHub. Не загружайте `.env`.
3. В Render откройте `New +` -> `Blueprint` и подключите репозиторий.
4. При создании сервиса вставьте ключ в секрет `LLM_API_KEY`.
5. Дождитесь статуса `Live` и откройте адрес сервиса.

## Проверка реального API

1. Откройте `<адрес-сервиса>/health`.
2. Проверьте: `apiConfigured` равно `true`, `demoMode` равно `false`.
3. Откройте главную страницу, измените тестовое описание идеи и нажмите «Получить разбор».
4. Убедитесь, что появился новый структурированный ответ без ошибки.

## Что приложить к домашнему заданию

1. Ссылку на опубликованный MVP Render.
2. Заполненный DOCX с этой же ссылкой.
3. Скриншот формы до отправки.
4. Скриншот результата после ответа ИИ.
5. Скриншот `/health`, где видны `apiConfigured: true` и `demoMode: false`.
