# AI-критик бизнес-идеи

Итоговый AI-MVP для подготовки бизнес-идеи к презентации. Пользователь описывает продукт, аудиторию, проблему и стадию проекта. AI возвращает критический разбор либо запрашивает недостающие данные, а профессиональные юридические и финансовые вопросы передаёт профильному специалисту.

## Результаты сценария

- `analysis`: резюме, 3 сильные стороны, 3 риска, 3 вопроса инвестора и следующий шаг;
- `clarification`: 1–3 уточняющих вопроса без выдуманного анализа;
- `handoff`: объяснение ограничения и указание нужного специалиста.

Системный промпт находится в `system-prompt.txt`. Ответ LLM проверяется на backend перед отправкой в браузер.

## Локальный запуск

```powershell
npm ci --ignore-scripts
$env:LLM_API_KEY='ваш_ключ_OpenRouter'
npm start
```

Откройте `http://localhost:3000`. Реальный ключ храните только в переменной окружения. Демо включается только локально через `DEMO_MODE=true` и принудительно отключается при `NODE_ENV=production`.

## Проверка

```powershell
npm test
npm audit --omit=dev
```

Health-check: `GET /health`. Для публичной версии ожидается `apiConfigured: true` и `demoMode: false`.

## Бесплатная публикация

Проект подготовлен для Render Blueprint:

1. Загрузите репозиторий в GitHub без `.env` и API-ключей.
2. В Render создайте Blueprint из репозитория — настройки берутся из `render.yaml`.
3. Добавьте секрет `LLM_API_KEY` от OpenRouter.
4. Дождитесь статуса `Live`, откройте публичный адрес и выполните контрольные запросы из `DEPLOY_CHECKLIST.md`.

Render Free засыпает после периода без входящих запросов, поэтому первый запуск после паузы может занять около минуты. OpenRouter `openrouter/free` не тарифицирует токены, но имеет лимиты бесплатного использования.
